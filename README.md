# HUB Library

## Description

HUB Library is a web application for managing a shared office library.

The application allows tenants to:

- browse available books;
- borrow books;
- return books.

Administrators can:

- add books;
- edit books;
- remove books;
- view borrowing history.

---

## Problem

Currently, book management is performed manually using a paper journal.
This makes it difficult to track available books and borrowing history.

---

## Goal

Create a simple web application that automates the library management process.

---
